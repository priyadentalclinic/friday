Proposed Changes
We will introduce a highly capable Proactive Action Engine, a Notification Interceptor, and Azure TTS.

1. Microsoft Azure TTS Integration
[NEW] com/friday/ai/voice/AzureTTS.kt
Integrate the Azure Speech REST API.
Configure the voice parameter to en-IN-NeerjaNeural or hi-IN-SwaraNeural to support English, Hindi, and Hinglish natively.
2. Proactive Notification Interceptor
[NEW] com/friday/ai/core/FridayNotificationService.kt
Extend NotificationListenerService.
Listen for incoming notifications (specifically com.whatsapp or SMS).
Extract the sender and message body.
Pass this to the MainViewModel to trigger a proactive LLM evaluation.
3. Context & State Engine (Driving & ETA)
[NEW] com/friday/ai/core/ContextEngine.kt
Track device speed using Location Services to determine if the user is DRIVING.
If a message arrives from "Mom" while DRIVING, the ContextEngine queries the Google Maps Directions API to get the ETA to Home.
It injects this into the LLM Prompt: “User is driving. ETA to Home is 29 mins. Received WhatsApp from Mom: 'When will you come home?'. Ask the user if they want to reply with the ETA.”
4. Action Execution Engine (Deep Intents)
[NEW] com/friday/ai/core/ActionExecutor.kt
Parse JSON actions from the LLM (e.g., {"action": "WHATSAPP_REPLY", "contact": "Mom", "message": "I will be there in 29 mins, stuck in traffic."}).
Call placing: Use Intent.ACTION_CALL.
Opening WhatsApp: Use Intent.ACTION_SEND targeting the WhatsApp package.
Opening Apps: Resolve package names and launch intents.
